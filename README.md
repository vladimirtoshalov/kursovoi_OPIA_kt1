
Курсовой проект: Система контроля облачной инфраструктуры 

Вариант 26

1. Для чего программа

Программа создана для контроля состояния серверов в облачной инфраструктуре на основе временных рядов телеметрических данных. Система собирает поступающие метрики, рассчитывает производные показатели динамики, определяет локальные состояния для каждого компонента и выявляет межкомпонентные инциденты на основе заданных логических правил

Отслеживаются 3 компонента:

SRV - нагрузка

RAM - объем задействованной оперативной памяти

TMP - температура

Порядок записи во входном потоке - значение, время, компонент. Порядок компонентов произвольный, возможны пропуски измерений

2. Математика программы (Производный показатель Q)

Для оценки динамики параметров вычисляется квадрат относительного изменения метрики. Формула для индивидуального варианта:

Q[i] = ((X[i] - X[i-k]) / X[i-k])^2

Константы:

Шаг сравнения: k = 2

Критерий изменения показателя: L = 1.5

Дополнительный нормирующий параметр: D = 20

3. Логика программы

Правило состояния компонента

Состояние каждого компонента на текущем шаге оценивается путем сравнения значения Q[i] с предыдущим Q[i-1]:

Если Q[i] > Q[i-1], то состояние "РОСТ"

Если Q[i] < Q[i-1], то состояние "СНИЖЕНИЕ"

В остальных случаях, то состояние "НОРМА"

Правило выявления инцидента:

В системе фиксируется инцидент при обнаружении противоположных состояний в один и тот же момент времени t. Если хотя бы один компонент находится в состоянии "РОСТ", а другой компонент одновременно в состоянии "СНИЖЕНИЕ", то выводится "Инцидент"

4. Ручной расчет и сравнение с выводом программы

Тестовые данные:

t = 1: SRV = 43.7, RAM = 53.8, TMP = 32.0

t = 2: SRV = 44.2, RAM = -1.0, TMP = 31.3

t = 3: SRV = 44.7, RAM = 55.2, TMP = 30.6

t = 4: SRV = -1.0, RAM = 53.2, TMP = 35.2

t = 5: SRV = 51.1, RAM = 51.2, TMP = 34.5

Расчет показателей Q:

t = 3:

Q_srv = ((44.7 - 43.7) / 43.7)^2 = 0.000524 (Состояние: Норма)

Q_ram = ((55.2 - 53.8) / 53.8)^2 = 0.000677 (Состояние: Норма)

Q_tmp = ((30.6 - 32.0) / 32.0)^2 = 0.001914 (Состояние: Норма)

t = 4:

Q_srv = -1.0 

Q_ram = -1.0 

Q_tmp = ((35.2 - 31.3) / 31.3)^2 = 0.015525 (Состояние: Рост)

t = 5:

Q_srv = ((51.1 - 44.7) / 44.7)^2 = 0.020500 (Состояние: Норма)

Q_ram = ((51.2 - 55.2) / 55.2)^2 = 0.005251 (Состояние: Норма)

Q_tmp = ((34.5 - 30.6) / 30.6)^2 = 0.016244 (Состояние: Рост)

Вывод программы полностью совпадает с ручным аналитическим расчетом.
